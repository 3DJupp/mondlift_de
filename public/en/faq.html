Where the sources disagree

There is no official database for a single travelling ride. What is public comes from directories kept by funfair enthusiasts, from reports and from Wikipedia, and these sources disagree in four places. Instead of picking one figure, both are given here:

Item The versions
Year the Mondlift was built 1976 or 1978
Speed up to 14 rpm for this ride, 14 to 17 rpm for the design
Enterprise rides built 74, about 50, over 75 or about 64, depending on whether rides built, delivered, sold or installed are counted
Return to the Wiesn after 2023 open; one source considers it doubtful, another rules it out

How this site works

Three rules by which the information here has been put together:

  1. Every figure names its source. At the end of each content page it says which source supports which statement, not as a blanket list but item by item.
  2. Disputed stays disputed. Where sources contradict each other, both values are given. A fan site that sounds more certain than its sources is worthless as a source.
  3. What is missing is visibly missing. This site keeps no calendar, quotes no prices and has no documents from the manufacturer. Where something is not documented, it says so.
Corrections

If you can prove or disprove a statement, with a photo, a type plate, an inspection log or a manufacturer's document, you are explicitly invited to get in touch. Documented corrections are worked in and the source is named.
